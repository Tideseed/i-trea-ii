**Overall.** The critique was right on every blocker. Two would have made pre-registered hypotheses untestable (the
Rank 0 quota was not a cap, and y did not change the survivors); two would have biased the main comparisons (selecting
the pool on a table that contains cuOpt, and an LP solved before the clock); two would have stopped the GPU EA on the
instances the study is about (memory and a local search costing O(nnz·P) per move). All were accepted. None was
rejected. Since the review, D-002 moved to v3 ([[D-007 Main claim — the coupling beats either method alone]]): the
primary hypothesis is now H1a (A3 < A0) **and** H1b (A3 < A5); "H1 = A3 < A2" in the critique's wording is now H3, and
the critique's H4/H5 (x and y ablations) are now H6 and an exploratory arm.

open 1 (M5: no commit or tag yet), rejected 0. Rows whose design and code exist but whose runs are still to make say so

**Status words.** *implemented* — in code or a decision record (tests named in the row where they exist); *partial* —
